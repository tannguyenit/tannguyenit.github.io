# tannguyenit.github.io

Blog cá nhân, dựng bằng [Astro](https://astro.build). Bài viết là Markdown trong `src/content/posts`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # xuất ra dist/
```

Deploy tự động bằng GitHub Actions khi push lên `master` (Settings → Pages → Source: GitHub Actions).
